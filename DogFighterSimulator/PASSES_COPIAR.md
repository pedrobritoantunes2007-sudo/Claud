# Gamepasses e Produtos (versão em inglês) — copie e cole

> O **PUBLICAR.bat faz tudo isto sozinho** (cria os itens novos e troca nome, descrição, preço e imagem dos antigos).
> Use esta lista só se quiser criar ou conferir algum item à mão.

Gamepass: create.roblox.com → seu jogo → Monetization → **Passes** → Create a Pass (depois Sales → Item for Sale → preço).
Produto: Monetization → **Developer Products** → Create a Developer Product.
Imagem de cada item: pasta `Imagens/Loja/<Chave>.png` (512×512, desenhada no estilo do jogo).
Depois cole cada ID em ReplicatedStorage → Shared → Monetization → `Monetization.IDS` (no item da coluna "Chave").
